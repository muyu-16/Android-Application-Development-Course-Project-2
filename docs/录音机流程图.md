# 录音机项目流程框图

## 整体架构

```mermaid
flowchart TB
    subgraph Init["初始化阶段"]
        A[页面加载 onMounted] --> B[从本地存储加载录音列表]
        B --> C[初始化 Recorder Manager]
        C --> D[初始化 Audio Context]
        D --> E[注册录音事件监听<br/>onStop / onStart / onError]
    end

    subgraph Record["录音流程"]
        F1[用户按下录音按钮] --> F2[startRecord 执行]
        F2 --> F3[recorder.start<br/>format: mp3<br/>sampleRate: 16000]
        F3 --> F4[onStart 回调触发]
        F4 --> F5[启动计时器<br/>显示录音时长]
        F4 --> F6[启动音量模拟<br/>绘制音量可视化]
        
        F7[用户松开按钮] --> F8[stopRecord 执行]
        F8 --> F9[recorder.stop 停止录音]
        F9 --> F10[onStop 回调触发<br/>获取 tempFilePath]
        F10 --> F11[生成录音时间戳]
        F11 --> F12[添加录音到 recordList]
        F12 --> F13[保存到本地存储]
    end

    subgraph Playback["播放流程"]
        G1[用户点击录音项] --> G2{是否正在播放<br/>且为同一项?}
        G2 -->|否| G3[设置音频源 src]
        G3 --> G4[设置播放速度 playbackRate]
        G4 --> G5[设置播放音量 volume]
        G5 --> G6[audio.play 开始播放]
        G6 --> G7[更新播放状态]
        
        G2 -->|是| G8[audio.pause 暂停播放]
        G8 --> G7
    end

    subgraph Control["控制功能"]
        H1[调整播放速度 slider] --> H2[onPlaybackRateChange]
        H2 --> H3{当前是否在播放?}
        H3 -->|是| H4[更新 audio.playbackRate]
        H3 -->|否| H5[仅保存设置]
        
        H6[调整播放音量 slider] --> H7[onVolumeChange]
        H7 --> H8{当前是否在播放?}
        H8 -->|是| H9[更新 audio.volume]
        H8 -->|否| H10[仅保存设置]
    end

    subgraph Delete["删除流程"]
        I1[用户点击删除按钮] --> I2[uni.showModal 确认框]
        I2 --> I3{用户确认?}
        I3 -->|是| I4{是否正在播放<br/>该录音?}
        I4 -->|是| I5[audio.stop 停止播放]
        I4 -->|否| I6[从 recordList 删除]
        I5 --> I6
        I6 --> I7[重新保存到本地存储]
        I3 -->|否| I8[取消删除]
    end

    subgraph Cleanup["清理阶段"]
        J1[页面卸载 onUnmounted] --> J2[清理录音计时器]
        J2 --> J3[清理音量更新计时器]
        J3 --> J4[停止并销毁 audio]
    end

    A --> E
    E --> F1
    E --> G1
    E --> H1
    E --> I1
    G7 --> Cleanup
    F13 --> Cleanup
```

## 模块说明

| 模块 | 描述 | 核心文件 |
|------|------|----------|
| 初始化阶段 | 页面加载时初始化录音管理器、音频上下文、加载历史记录 | record.vue:117-186 |
| 录音流程 | 长按开始录音，松开停止，保存到本地存储 | record.vue:212-252 |
| 播放流程 | 点击录音项进行播放/暂停，支持速度/音量调节 | record.vue:286-298 |
| 控制功能 | 播放速度和音量的实时调节 | record.vue:322-334 |
| 删除流程 | 带确认框的录音删除功能 | record.vue:300-320 |
| 清理阶段 | 页面卸载时释放资源 | record.vue:202-210 |

## 数据流向

```
用户操作 → 状态更新 → UI渲染 → 本地存储
```

录音文件存储路径: `tempFilePath` (临时文件)

录音列表存储: `uni.setStorageSync('recordList', recordList.value)`
